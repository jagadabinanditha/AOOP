# Practical 1 – Waypoint Parking Management

## Files
This project is split into separate Java files:
- CustomerId.java
- BookingId.java
- ParkingSpotId.java
- PaymentId.java
- Money.java
- Customer.java
- SpotStatus.java
- ParkingSpot.java
- ParkingSpotView.java
- Payment.java
- BookingStatus.java
- Booking.java
- Waypoint.java
- WaypointDemo.java

## Run in VS Code terminal
Open this folder in VS Code, then run:

```bash
javac *.java
java WaypointDemo
```

Requires Java 16 or later because the program uses records. Java 21 is recommended.
